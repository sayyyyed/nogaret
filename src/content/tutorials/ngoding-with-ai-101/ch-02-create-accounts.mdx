Di bab sebelumnya kamu sudah menginstall empat tool inti. Sekarang kamu butuh dua akun: **GitHub** untuk menyimpan dan berkolaborasi pada kode, serta **ChatGPT** sebagai otak AI di balik Codex.

<Callout type="info" title="Satu email untuk semua">
Gunakan satu alamat email yang sama untuk kedua akun agar semuanya rapi dan mudah diingat.
</Callout>

## GitHub

<ToolCard icon="github" name="GitHub" url="https://github.com/" badge="Hosting kode & kolaborasi">
<p>GitHub adalah tempat penyimpanan *repository* kode terbesar di dunia. Di sinilah kamu menyimpan proyek, berkolaborasi dengan orang lain, dan (nanti) menampilkan portofolio coding kamu.</p>
<p>Git yang kamu install di bab sebelumnya terhubung langsung ke GitHub lewat perintah `git push` dan `git pull`.</p>
</ToolCard>

Buka [github.com/signup](https://github.com/signup), isi email, buat *password*, dan pilih username. Selesai, pastikan kamu memverifikasi email dari GitHub di kotak masuk kamu.

<Callout type="tip" title="Pilih username dengan bijak">
Username kamu akan tampil di URL profil, misalnya `github.com/username-kamu`. Pilih yang profesional dan konsisten dengan media sosial lain karena ini jadi identitas publik kamu.
</Callout>

## ChatGPT

<ToolCard icon="openai" name="ChatGPT" url="https://chat.openai.com/" badge="Asisten AI">
<p>ChatGPT adalah asisten AI dari OpenAI. Di seri ini kamu menggunakannya untuk bertanya, memahami konsep, dan memecahkan masalah saat belajar coding.</p>
<p>Akun ChatGPT ini juga dipakai untuk login ke Codex — agen coding AI yang kamu install di bab sebelumnya.</p>
</ToolCard>

Buka [chat.openai.com](https://chat.openai.com/) lalu pilih **Sign up**. Daftar dengan email (atau akun Google/Apple). Jika kamu sudah punya akun, langsung saja **Log in**.

<Callout type="success" title="Koneksi selesai">
Setelah akun ChatGPT aktif, kembali ke terminal dan jalankan login Codex. Begitu berhasil, alur "menulis kode dengan bantuan AI" sudah benar-benar siap.
</Callout>

## Keamanan akun

<OptionalPanel title="Keamanan akun">
<p>Beberapa kebiasaan kecil yang membuat akun kamu lebih aman. Tidak wajib untuk lanjut, tapi sangat disarankan.</p>
<ul>
<li>Aktifkan **Two-Factor Authentication (2FA)** di GitHub (Settings → Password and authentication).</li>
<li>Jangan pernah membagikan *password* atau *token* ke siapa pun — termasuk ke AI.</li>
</ul>
</OptionalPanel>
